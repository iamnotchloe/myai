## 当前已经实际跑出的结果

离线题集共32题，其中27题可回答、5题应该拒答。当前已完成27条可回答题的页面级召回测试：

| 方案 | Hit@1 | Hit@3 | Hit@10 | MRR@10 |
|---|---:|---:|---:|---:|
| 当前空白分词BM25 | 0.148 | 0.185 | 0.370 | 0.189 |
| 当前BGE Dense | 0.852 | 0.963 | 1.000 | 0.910 |
| 空白BM25 + Dense的RRF模拟 | 0.333 | 0.519 | 0.926 | 0.488 |
| 中文字符BM25 | 0.889 | 0.963 | 1.000 | 0.932 |
| 中文字符BM25 + Dense RRF | 0.852 | 1.000 | 1.000 | 0.920 |

更新说明：2026-08-30第一轮P0优化已经把中文字符BM25和RRF接入后端，并保留Dense、BM25、RRF、Reranker四阶段的rank与score。表中的RRF已从离线模拟变为当前实现；完整端到端准确率仍需扩大并冻结测试集后再测。

端到端只完成3题冒烟测试：3/3答案关键事实正确，3/3引用命中，平均耗时约10.49秒。样本太少，不能把这个结果称作整个系统100%准确。

这些数字只是创建文档前完成的第一轮工具自检。按照你的要求，当前阶段先不继续运行全量评测或调用更多API；正式项目评测结果要等题集人工复核、开发集/测试集拆分并冻结后再生成。

## 当前结果说明

> 我在7.17原始项目上完成了多文档扩展和第一轮工程调优；目前已经发现并修复重复索引和跨公司错配，并建立了分层评测工具。第一版27题离线结果显示，Dense召回较好，中文BM25的空白分词是明显短板。换成中文字符分词后BM25 Hit@10从0.370提升到1.000；再与Dense做RRF，Hit@3达到1.000。这个结果仍属于小规模开发评测，下一步需要扩充并冻结测试集，再跑完整端到端和拒答评测。
